One rack for every ShopBot Labs app in this browser (the STEP
            toolpath app reads the same one). Exports post these exact numbers, so they must match your machine's
            toolchanger or collet workflow. Bits the rack lacks post a spare number and a warning naming them.

With a material chosen, every rack-matched bit runs chipload-derived feed, plunge, and RPM
          (per-tool TR in the file) instead of each strategy's stock numbers — deterministic tables, no guessing. "Keep
          app feeds" leaves everything exactly as before.

"Send to FabMo" queues the job on the tool — you still press run
            there. "Send & run" starts it only when the machine is idle and yours is the only queued job; check the
            bit, Z zero, and that the deck is clear before using it. Over https your browser
            must allow local-network access for this page (Chrome asks the first time — if a scan finds nothing, that
            permission is the first thing to check; Loom on your shop's own http server needs no permission).
